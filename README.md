# Meus-Projetos
Neste repositório estão alguns projetos que envolvem analise de dados, desenvolvimento de Dashboards e KPIs 


Portfólio — Tecnologia, Dados e Automação

Sobre mim:

Sou estudante de Análise e Desenvolvimento de Sistemas no IFCE e técnico em Informática, com experiência prática no desenvolvimento de soluções utilizando tecnologia, automação, integração de sistemas, bancos de dados e análise de dados.
Durante minha atuação na Parceria Consultores, empresa de consultoria e tecnologia, trabalhei no desenvolvimento de soluções para diferentes necessidades de clientes, tendo contato com CRMs, ERPs, Pipefy, n8n, Supabase, SQL e Google Looker Studio.

Essa experiência me permitiu trabalhar não apenas com desenvolvimento, mas também com a organização, integração e análise de dados utilizados nos processos dos clientes.

Contexto e experiência: 

Grande parte dos projetos surgiu da necessidade de centralizar informações, estruturar processos e transformar dados operacionais em informações úteis para gestão e tomada de decisão.

- Pipefy (Plataforma online de gestão e automação de fluxos de trabalho)
- N8N (Ferramenta para automação e integração entre sistemas. Estilo low-code)
- SupaBase (É uma plataforma de Back-end-as-a-Service, com banco de dados PostgreSQL integrado. Banco de dados relacional.
